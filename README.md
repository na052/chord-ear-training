# Chord Notes — コード聴き取りクイズ

和音を聴いて具体的なコード名を4択から選ぶ、日本語の耳トレWebアプリです。React / TypeScript / Vite / Tone.jsを使用します。アカウント・バックエンド・外部音源は不要です。

## 環境構築と起動

Node.js **24 LTS（24.15以上）**、npmが必要です。

```bash
git clone https://github.com/na052/chord-ear-training.git
cd chord-ear-training
npm install
npm run dev
```

ターミナルに表示されるURL（通常 `http://127.0.0.1:5173`）を開きます。PRの変更を確認する場合は、インストール前に `git switch feat/chord-ear-training` で実装ブランチへ切り替えてください。依存バージョンを固定して再現する場合は `npm ci` を使います。

```bash
npm run build     # TypeScriptチェック + dist/ に本番ビルド
npm run preview   # 本番ビルドのローカル確認
```

## 使い方

1. 初級・中級・上級と、練習・テストを選び「トレーニングをスタート」。
2. 「コードを再生」で和音を聴き、4択からコード名を選びます。繰り返し再生できます。
3. 練習では「低い音から順に再生」「基準音 C」を利用できます。
4. 回答後に正誤・正解コード・構成音・解説を確認し、次の問題へ進みます。
5. 10問終了後に正答数・正答率を表示します。練習ではヒント使用問題数とヒント未使用正解数も表示します。

- 数字 **1〜4**：回答。**Space**：コード再生。入力欄・ボタンなどの操作中はショートカットを抑止し、通常のキーボード操作を優先します。
- 音量は全画面で調整できます。「再生停止」、回答、問題切替、設定への移動、タブ非表示時に音を停止します。
- 音は「再生」などのユーザー操作後に鳴ります。鳴らない場合はアプリ・端末の音量、ミュート、出力先、ブラウザの音声設定を確認してください。音声初期化が失敗した場合は画面にエラーを表示します。
- 途中で設定へ戻ると、そのセットの回答は破棄されます。

## 出題と音声

- 12ルート（C / C# / D / Eb / E / F / F# / G / Ab / A / Bb / B）。表示上の異名同音はこの表記に統一します。理論上の綴り（E#など）とは異なる場合があります。
- 初級：major / minor。中級：初級 + 7 / maj7 / m7 / 9 / maj9 / m9。上級：中級 + dim / dim7 / m7b5 / aug。
- 9th系は7thを含む5音。基本形のみ、ルートC3〜B3、A4=440Hzです。
- 和音は同時に発音して約1.5秒保持し、約0.5秒で減衰します。分解再生は低音から0.5秒間隔です。
- 4択は常に異なる名前で正解は1つ。同一ルートの別種類を優先し、足りない場合は別ルートを加えます。1セット10問の出題コードはすべて異なります。一度出題したコードは、そのセットでは再出題しません（不正解の選択肢としては表示される場合があります）。新しいセットでは再び出題対象になります。
- `AudioEngine` インターフェースを実装することで、今後Tone.Samplerなどへ差し替えられます。

## 学習記録

完了したセットの日時・難易度・モード・正答数・ヒント使用問題数などを `localStorage` の `chord-notes.sessions.v1` に保存します。最大100件を保持し、ホームには直近5件を表示します。基準音の利用もヒントとして数え、同じ問題で両方を使っても1問として集計します。回答後のヒント利用は成績に影響しません。

記録は同じブラウザ・同じオリジンでのみ共有されます。閲覧データの削除で消え、端末間の同期はありません。保存不可・データ破損時はメッセージを表示し、クイズは続行できます。破損した履歴は自動上書きしません。

## テスト

```bash
npm test                         # コード生成・集計・保存・UI・音声エンジン
npx playwright install chromium  # 初回のみ（Linux CIは --with-deps を追加）
npm run test:e2e                  # 開発サーバーを自動起動してブラウザテスト
```

- 単体・結合テスト：全12種類×12ルートの構成音、各難易度で100セットの選択肢検証、セット全体での出題重複回避・次セットでのリセット、ヒント集計、保存エラー、キーボード操作、二重回答防止、再生停止・非同期開始の取消。
- E2E：デスクトップとモバイル幅のChromiumで3難易度×2モードを10問完走し、正答率・ヒント・再読込後の履歴・再挑戦を確認します。実際のTone.jsでAudioContextの起動と再生操作も確認します。
- GitHub Actionsで単体テスト・ビルド・E2Eを実行します。
- 自動テストではスピーカーからの実音の聴感や実機Safari/iOSの音声挙動までは検証できません。

## 構成

```text
src/
  App.tsx                 設定・出題・結果画面とセッション制御
  styles.css              レスポンシブUI
  audio/AudioEngine.ts    Tone.jsシンセ、音量・停止・分解再生
  domain/chords.ts        コード定義、MIDI・音名変換
  domain/quiz.ts          出題・4択生成、結果集計、型定義
  domain/storage.ts       履歴の検証・保存
  **/*.test.ts(x)         単体・結合テスト
tests/quiz.spec.ts        ブラウザE2E
chord_ear_training_spec.md 元仕様書
```

初期版では転回形、分数コード、サンプル音源、苦手コード分析は実装していません。

技術資料：[Vite](https://vite.dev/guide/) / [Tone.js PolySynth](https://tonejs.github.io/docs/15.1.22/classes/PolySynth.html)
